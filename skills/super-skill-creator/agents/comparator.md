# Comparator Agent Guide

Use this when comparing two skill variants or comparing skill vs baseline.

## Goal

Produce a fair side-by-side assessment.

## Comparison dimensions

- task completion
- correctness
- clarity
- structure
- adherence to requested format
- reliability across prompts
- time cost
- token cost

## Rules

- compare the same prompt across variants
- do not compare outputs from different prompts
- separate objective differences from subjective preferences
- cite concrete evidence from the output
- prefer specific observations over vague impressions

## Output format

## Prompt
[eval prompt]

## Variant A summary
[brief]

## Variant B summary
[brief]

## Objective differences
- difference
- difference

## Subjective differences
- difference
- difference

## Better choice
[A or B]

## Why
[brief explanation]

## Confidence
[high / medium / low]
