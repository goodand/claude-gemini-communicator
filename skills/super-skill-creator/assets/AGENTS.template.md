# AGENTS.md

## Skill routing hints

Use `super-skill-creator` when the task involves:

- creating a new Agent Skill
- improving an existing Agent Skill
- converting a repeated workflow into a skill
- adding scripts, references, or assets to a skill
- creating eval prompts for a skill
- comparing with-skill vs baseline outputs
- improving skill triggering or routing
- packaging a skill for reuse

Prefer this skill over generic writing or generic coding skills when the user is
explicitly talking about skill creation, skill improvement, skill packaging, or
skill evaluation.
