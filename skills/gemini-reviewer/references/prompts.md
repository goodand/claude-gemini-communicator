# 리뷰 프롬프트 템플릿

## 코드 리뷰 (기본)

다음 코드를 리뷰해줘:
- 버그 또는 잠재적 오류
- 보안 취약점 (인젝션, 하드코딩된 비밀 등)
- 에러 처리 누락
- 개선 제안
간결하게 한국어로 답해줘.

## 문서 평가 (기본)

다음 문서를 평가해줘:
- 논리적 일관성
- 실현 가능성
- 누락된 고려사항
- 개선 제안
간결하게 한국어로 답해줘.

## 보안 집중 리뷰

다음 코드의 보안 취약점을 집중 분석해줘:
- OWASP Top 10 해당 여부
- 입력 검증 누락
- 인증/인가 취약점
- 하드코딩된 비밀/토큰
간결하게 한국어로 답해줘.

## 아키텍처 리뷰

다음 설계를 아키텍처 관점에서 평가해줘:
- 관심사 분리 (SoC) 수준
- 확장성과 유지보수성
- 과설계/부족설계 여부
- 대안 제시
간결하게 한국어로 답해줘.
