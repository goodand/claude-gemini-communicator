# Agent Flow

## Procedural Flow

This flow is condition-based, not time-based.

1. `dependency-slice-planner`
- Entry condition: repository scope and planning target are fixed.
- Output gate: `slice_manifest.json` plus per-slice `handoff_packet.json` and `context-links.md` exist.

2. `codebase-analysis`
- Entry condition: slice artifacts exist.
- Output gate: selected agent packages, task packets, and context-routing choices are fixed.

3. `dependency-graph-analyst`
- Entry condition: a slice packet contains code/manifest/wrapper links.
- Output gate: graph summary, edge list summary, and boundary summary exist.

4. `dependency-risk-auditor`
- Entry condition: graph artifacts exist.
- Output gate: unsafe crossings, coupling risks, and mitigation notes exist.

5. `context-broker`
- Entry condition: multiple worker outputs exist.
- Output gate: overlap, missing evidence, and unresolved relations are compacted into relay artifacts.
- Scope note: broker performs fan-in gap handling, not final synthesis.

6. `reviewer`
- Entry condition: broker output or worker artifacts need quality review.
- Output gate: missing evidence, contradictions, and weak claims are explicitly listed.

7. `synthesizer`
- Entry condition: worker summaries, broker notes, and review findings exist.
- Output gate: one final synthesis report, one deduplicated finding map, one contradiction-resolution note, and one residual gap register.

## Backtrack Rules

- If graph evidence is missing, do not run the risk auditor yet; return to `dependency-graph-analyst`.
- If worker outputs overlap or leave holes, return to `context-broker` before synthesis.
- If review finds unsupported claims, return to the producing worker or broker instead of patching inside synthesis.
- If synthesis still contains unresolved contradictions, emit them in the residual gap register rather than flattening them.
