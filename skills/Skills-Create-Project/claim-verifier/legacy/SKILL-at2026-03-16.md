# Claim Verifier

주장(claim)을 항목별로 분해하고, 코드/문서/파일 근거를 찾아 참·거짓·부분참으로 판정한다.

## When to use

- 외부 피드백이나 리뷰 코멘트가 사실인지 확인할 때
- "구현됐다", "지원한다", "완료됐다" 같은 주장을 증거로 검증할 때
- 문서 서술과 실제 artifact 존재 여부를 대조할 때
- 여러 claim을 표 형태로 판정해야 할 때

## Workflow

1. **claim 분해** — `scripts/claim_verifier.py extract --input <file>` → 검증 가능한 claim 목록 추출
2. **증거 수집** — `scripts/claim_verifier.py verify --claims <claims.json> --repo <path>` → 파일/라인/문서 증거 수집
3. **판정** — true / false / partial / unverifiable로 분류
4. **보고** — `scripts/claim_verifier.py report --results <results.json>` → claim별 증거와 조치 가이드 출력

## Scripts

- `scripts/claim_verifier.py` — extract/verify/report 스캐폴드. `python3 scripts/claim_verifier.py --help`

## Notes

- claim은 항상 **검증 가능한 최소 단위**로 쪼갠다
- line evidence 없이 "맞는 것 같다"로 판정하지 않는다
- unverifiable은 false와 다르다 — 증거 부족 상태를 따로 둔다
- doc-code-sync-checker와 달리 시작점은 **문서/자연어 claim**이다
