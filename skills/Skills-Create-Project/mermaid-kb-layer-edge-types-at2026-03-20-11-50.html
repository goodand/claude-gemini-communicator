KB Layer With Typed Edges

인접리스트를 먼저 두고, 그 관계를 Mermaid edge type 4종으로 내린 버전. `contains`, `feeds`, `constrains`, `escalates_to`를 분리했다.

Mermaid 로딩 중...

Edge Legend

contains — layer가 내부 하위 구조를 가진다.
feeds — 다음 판단층이나 산출물로 직접 입력을 공급한다.
constrains — 행동 가능 범위를 제한한다.
escalates_to — 자동 처리 한계를 넘겨 HITL로 올린다.

이번 버전에서 바뀐 점:

  • 그래프를 바로 그리지 않고 인접리스트를 먼저 노출해서 edge 타입 판단 근거를 남겼다.
  • contains는 내부 구조, feeds는 입력 흐름, constrains는 제약, escalates_to는 HITL 상승 경로로 분리했다.
  • boundary는 단독 source가 아니라 여러 KB가 함께 feed하고 constrain하는 판정층으로 표현했다.
