# Semantic Slice Mapper

개념 공간의 표현을 semantic slice relation으로 정리하는 스캐폴드.

## When to use

- 자연어, Mermaid, LaTeX, 수도코드가 같은 개념을 어떻게 표현하는지 정리할 때
- 상위 개념과 하위 개념 slice를 구분할 때
- 구현 전에 의미/경계/목적을 먼저 고정할 때

## Workflow

1. 개념 표현 수집
2. semantic slice 추출
3. 경계/포함 관계 정리
4. 실행 계약 공간으로 넘길 요약 작성
