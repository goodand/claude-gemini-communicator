# Routing hints for --help

## Trigger this skill when

- the user wants to perform the primary workflow
- the user wants to create or improve artifacts in this domain
- the task strongly involves the skill's domain

## Do not trigger this skill when

- the task is only loosely related
- a more specific neighboring skill clearly fits better
- the user is asking for general discussion rather than task execution
